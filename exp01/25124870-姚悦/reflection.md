# 实验一：Word2Vec 词向量实验心得

通过本次实验，我对 Word2Vec
词向量模型的基本原理和实际应用有了更加深入的认识。本次实验主要围绕窗口大小（window）的不同设置展开，通过分别设置
window=2 和
window=5，观察不同上下文范围对词向量训练及词语相似度分析的影响。

在实验开始前，我首先了解并整理了英文文本数据的预处理流程。代码中使用
Unicode NFKC 规范化、HTML 实体解码、HTML
标签清理以及英文小写转换等操作，再通过正则表达式提取单词和数字。实验还提供了是否去除停用词的选项。通过阅读和实现这一部分，我认识到，文本预处理并不是简单地删除无用字符，不同的处理方式可能会影响词语出现的频率和上下文关系。例如，代码在去除停用词时保留了否定词，这让我意识到，像"not"和"never"这样的词虽然常见，但对表达语义和情感倾向具有重要作用，不能不加区分地删除。

本次实验的重点是比较 window=2 和 window=5
两种窗口设置。窗口大小决定了模型在训练过程中能够关注目标词周围多大范围的上下文。较小的窗口更侧重于距离目标词较近的上下文，而较大的窗口能够纳入更远位置的词语。因此，两种设置可能学习到不同的词语关联信息。通过对比实验，我进一步理解到，窗口大小是影响
Word2Vec
词向量表示的重要参数，参数选择需要结合语料特点和具体任务来考虑，不能简单地认为窗口越大或越小就一定越好。

在模型训练方面，代码使用 Gensim 中的 Word2Vec，并支持 CBOW 和 Skip-gram
两种训练算法。实验固定了随机种子、训练线程数、学习率以及负采样等参数，尽可能减少其他因素对对比结果的干扰。这种控制变量的思路让我认识到，进行算法实验时，除了关注实验结果，还必须注意实验条件是否一致。只有在其他主要参数保持一致的情况下，窗口大小的对比才更有参考价值。

为了分析训练结果，代码不仅保存了模型和词向量，还计算了指定词语之间的余弦相似度，并为查询词寻找最相近的五个词。同时，对于不在模型词汇表中的词语，程序会标记为
OOV。这让我认识到，词向量实验不能只看模型是否成功训练，还需要通过具体的相似词和近邻词结果来理解模型学到了什么。另外，代码使用
PCA 或 t-SNE
将词向量投影到二维空间，并生成可视化图像，使原本难以直接观察的高维词向量关系更加直观。不过，二维投影主要用于探索和观察，不能直接把图上的距离当作模型语义关系的绝对结论。

我还注意到，代码对数据使用过程进行了检查，例如避免将开发集或测试集文件作为训练数据，并检查训练文本是否与排除文件中的文本重复。这些处理让我认识到，数据泄漏会影响实验结论的可靠性，实验数据的划分和管理与模型本身同样重要。除此之外，程序还保存了训练数据的
SHA-256
摘要、预处理配置、软件版本、模型参数和运行状态等信息，并导出了词表、词向量矩阵以及预处理配置文件，为后续实验复用模型提供了便利。这让我体会到，完整的实验不仅要得到结果，还应当保留清晰的实验记录，使实验过程能够被检查和复现。

通过本次实验，我最大的收获是对自然语言处理实验的完整流程有了更清楚的认识：从原始文本读取、数据清洗和分词，到模型训练、参数对比、相似度分析、结果可视化，再到实验记录和模型导出，每个环节都会影响最终结果。同时，我也认识到，代码能够生成比较结果，并不意味着可以不加分析地得出结论。后续还需要结合实际生成的
`comparison.csv`、`word_pairs.csv`、`neighbors.csv`
和可视化图像，具体分析两种窗口设置的差异。

总的来说，本次实验让我掌握了 Word2Vec
实验的基本操作，加深了对上下文窗口、词向量相似度以及实验可复现性的理解，也锻炼了我阅读代码、控制实验变量和分析实验结果的能力。今后在进行类似实验时，我会更加注意数据质量、参数控制和结果解释，尽量让实验结论建立在真实、完整的数据和观察结果之上。
