# 实验一小结
        本次实验借助gensim的Wordsvec模型学习了如何训练模型，导入模型和库->数据预处理->文本去重->数据隔离检查->训练模型。其中，数据预处理有清洗，分词，设置min_count截断低频词，使用基础停用词；文本去重有训练数据内部去重；数据隔离检查则是通过检测处理好的数据是否和实验二的测试于验证集重合；训练模型通过固定参数，仅调整window值为2或5。通过top-5近邻词查询比较了窗口值对模型训练的影响，并且通过PCA降维随后作图直观了解了词块的分布，除此之外，还发现通过这种方式训练出来的词无法判断语义上的差别，如good-bad的词对相似度较接近。
        本次实验最大的收获是自己对代码使用和整合，环境的调整配置，镜像下载训练数据等基础操作的学习，从完全不懂到稍微入门的转变。除此之外，还有对无监督学习的一种方式的深入了解，和对模型训练大体结构和过程的学习，甚至是借助人工智能修改和学习代码时，对人工智能的提示词的书写和调用更加得心应手。我清楚自身在代码学习以及基础知识上的欠缺，借助边学边练得方式我能感觉到自己的能力有一定的提升。
